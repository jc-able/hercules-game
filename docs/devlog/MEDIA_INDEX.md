# Hercules · Media index

Before/after screenshots for every change. JPEG, quality 80, at most 1600 px wide, in `media/<NN_chapter>/`. Pairs taken from
the identical camera/scene are marked **same view** (they work as wipe or slider transitions). When no true "before" exists the
row says so. Nothing here shows an email, account, device ID, key or private path.

Clips: MP4 (H.264, <= 1080p, <= 40 MB), each with a poster JPEG of the same name. "match" clips are short loops repeated
several times so they play long enough on screen. Captions with numbers come from the agents' notes (media_inbox captions,
checked against the images) and from the lead log / Higgsfield ledger. The plan with all file names: [media_plan.md](media_plan.md).
